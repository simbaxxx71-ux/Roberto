# Поиск оригинальных автозапчастей по артикулу

Приложение ищет цены на оригинальные (OEM) запчасти: парсит сайты магазинов
и опрашивает API продавцов (формат ABCP, совместим с v01.ru).

## Запуск на компьютере

    pip install -r requirements.txt
    streamlit run app.py

Откроется http://localhost:8501

## Запуск с iPhone (через браузер Safari)

### Способ 1 — Streamlit Community Cloud (бесплатно, без компьютера)

1. Заведите аккаунт на github.com.
2. Создайте публичный репозиторий (кнопка «New repository», поставьте галочку Public).
3. В репозитории нажмите «Add file» → «Upload files» и загрузите три файла:
   app.py, parsers.py, requirements.txt (README.md — по желанию).
4. Откройте share.streamlit.io, войдите через GitHub → «Create app» →
   выберите репозиторий, ветку main, файл app.py → Deploy.
5. Через 1–2 минуты получите адрес вида https://имя.streamlit.app
6. Откройте его в Safari на iPhone → «Поделиться» → «На экран "Домой"».
   Появится иконка — запуск как у обычного приложения.

### Способ 2 — домашний компьютер + туннель

На компьютере (в одной сети Wi-Fi с iPhone):

    streamlit run app.py --server.address 0.0.0.0

На iPhone в Safari откройте http://IP-КОМПЬЮТЕРА:8501
(IP компьютера можно узнать в настройках сети; например 192.168.1.5).

Либо через туннель (работает и вне домашней сети):

    pip install streamlit && streamlit run app.py
    cloudflared tunnel --url http://localhost:8501

Появится адрес вида https://что-то.trycloudflare.com — откройте его в Safari.
Плюс: запросы к сайтам идут с домашнего IP, капч меньше.

## Получение доступа к API продавцов

- v01.ru — регистрируетесь, API совместим с ABCP, включается после первого
  входа в личный кабинет. В приложении: панель настроек → «API продавцов».
- Поставщики на платформе ABCP — хост вида https://idXXXXX.public.api.abcp.ru,
  логин и пароль от личного кабинета поставщика.
- Berg — ключ создаётся в личном кабинете (Мой профиль → API).
- Exist, Emex, Autodoc — открытых API нет, только партнёрский доступ
  через договор (Emex: wsdoc.emex.ru, Autodoc: partnerapi.autodoc.ru).

Пароль/ключ вводятся только в панели настроек и не сохраняются.

## Примечания

- В бесплатном Streamlit Cloud репозиторий должен быть публичным;
  секретов в коде нет, доступы хранятся только в памяти сессии.
- После ~15 минут простоя приложение «засыпает»: первый заход занимает
  около 30 секунд.
